# CodeAlpha Task 1 – Hangman Game

## Project Description
A simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Randomly selects a word from a list of 5 predefined words.
- Allows the player to guess one letter at a time.
- Maximum of 6 incorrect guesses.
- Displays correctly guessed letters and hidden letters.
- Detects win and game-over conditions.

## Technologies Used
- Python
- Random module
- While loop
- If-else statements
- Strings and lists

## How to Run
1. Install Python.
2. Open the project folder in VS Code or Command Prompt.
3. Run:

`python hangman.py`
